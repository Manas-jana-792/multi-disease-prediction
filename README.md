# 🏥 Multi Disease Prediction System

A full-stack Machine Learning web application that predicts the risk of **Heart Disease**, **Stroke**, and **Diabetes** using patient health data. Built with a production-style architecture — **FastAPI backend** serving ML models, and a **Streamlit frontend** for the user interface.

## 📐 Architecture

```
Streamlit (Frontend)  →  FastAPI (Backend API)  →  Trained ML Models  →  JSON Response
```

This separates the UI from the prediction logic, mirroring how real-world ML systems are deployed in production.

---

## 🧠 Models Used

| Disease | Best Model | Metric |
|---|---|---|
| 🫀 Heart Disease | Logistic Regression | ROC-AUC ≈ 0.90 |
| 🧠 Stroke | Logistic Regression | ROC-AUC ≈ 0.84 |
| 🩸 Diabetes | XGBoost | ROC-AUC ≈ 0.97 |

All models were trained on real, publicly available healthcare datasets and compared against Decision Tree, Random Forest, KNN, and XGBoost before selecting the best performer.

## 🛠️ How to Run Locally

### 1. Clone the repository
```bash
git clone <your-repo-url>
cd multi-disease-prediction
```

### 2. Start the FastAPI backend
```bash
cd backend
pip install -r requirements.txt
uvicorn main:app --reload
```
Backend runs at `http://127.0.0.1:8000`
Interactive API docs at `http://127.0.0.1:8000/docs`

### 3. Start the Streamlit frontend (in a new terminal)
```bash
cd frontend
pip install -r requirements.txt
streamlit run streamlit_app.py
```
Frontend runs at `http://localhost:8501`

> ⚠️ Make sure the backend is running before starting the frontend.

## 🔬 Data Preprocessing

- `StandardScaler` for numerical features
- `OneHotEncoder` for categorical features
- `ColumnTransformer` to combine pipelines
- `SMOTE` to handle class imbalance (Stroke & Diabetes datasets)
- Feature engineering for Stroke model (age groups, BMI categories)
